# Размер CLI-артефактов

Замер 2026-09-19: macOS amd64 (x86_64), файлы Mach-O, без сжатия.
Go 1.27.1, `-trimpath -ldflags="-s -w"` для новых Breach-сборок.
Это размеры файлов, не RSS. У установленного sing-box набор функций шире;
сравнение не означает одинаковую функциональность.

| Артефакт / поставка | Байты | МиБ |
|---|---:|---:|
| **Единый breach: TURN + Hy2/gVisor + routing + reconnect + macOS utun + TUI** | 15569264 | 14.85 |
| Единый breach до добавления TUI | 15249232 | 14.54 |
| Предыдущее раздельное Hy2-ядро с routing | 12815472 | 12.22 |
| Отдельный TURN-клиент | 10025328 | 9.56 |
| Предыдущая новая связка из двух файлов | 22840800 | 21.78 |
| Установленный sing-box | 53949856 | 51.45 |
| Прежняя связка sing-box + TURN | 63975184 | 61.01 |

TUI, горячие настройки и метрики добавили 320032 байт (0.31 МиБ, 2.10%).
Единый файл меньше предыдущей двухпроцессной сборки на 31.8%,
а прежней связки с установленным sing-box — на 75.7%.
Общие Go runtime и библиотеки больше не дублируются в двух executable.

`breach-native` теперь совместимая команда того же движка, с mode=pipe по
умолчанию; тоже 14.85 МиБ. Для обычного запуска достаточно **одного breach**.
`breach-client` оставлен для старого способа запуска.

Новый CLI не содержит sing-box/libbox, `breach/qtun`, SagerNet QUIC или WireGuard
в `go list -deps ./cmd/breach`. SagerNet остаётся только в legacy-тестах модуля.

Воспроизведение: `sh scripts/build-desktop.sh`, затем `stat`/`wc -c` файла
`../../breach/bin/breach`.
